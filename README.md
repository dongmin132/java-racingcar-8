# java-racingcar-precourse

---

## 구현 목표
주어진 횟수 동안 n대의 자동차가 전진 또는 멈춤을 반복하는 자동차 경주 게임을 구현한다.
경주 종료 후 우승자(한명 이상 가능) 를 출력하며, 잘못된 입력값이 들어올 경우 `IllegalArgumentException`발생 후 프로그램을 종료한다.

---

## 기능 요구 사항
### 입력 형식
- 자동차 이름은 쉼표(`,`) 기준으로 구분   
  예) pobi,woni,jun
- 각 자동차 이름은 1자 이상 5자 이하
- 시도할 이동 횟수는 정수로 입력
- 잘못된 입력 (빈 값, 6자 이상, 음수, 비정수 등)은 `IllegalArgumentException`발생 후 프로그램 종료

### 동작 규칙
- 각 자동차는 매 라운드마다 0~9 사이 난수를 생성
- 난수가 4이상일 경우 전진, 그 미만이면 그대로
- 각 라운드 결과를 자동차 이름과 함께 출력   
  예) pobi : --
- 모든 시도가 끝난 뒤 가장 멀리 간 자동차(우승 중복 가능) 가 우승자가 됨
- 우승자가 여러 명일 경우 쉼표(`,`)로 구분하여 출력   
  예) 최종 우승자: pobi, jun

---

## 기능 목록
### 1. 입력 처리 (input)
- 사용자로부터 자동차 이름 목록과 이동 횟수를 입력
- 자동차 이름 입력: 
  - 쉼표(`,`)로 구분된 문자열 입력
  - 이름은 공백 불가, 빈 문자열 불가, 길이 5자 이하
- 이동 횟수 입력:
  - 1 이상의 정수만 허용
- 잘못된 입력일 경우 `IllegalArgumentException` 발생

### 2. 구분자 및 이름 파싱 (parser)
- 쉼표(`,`)를 기준으로 자동차 이름 분리
- 이름 목록을 List<String> 형태로 반환
- 중복 이름이 존재하면 `IllegalArgumentException` 발생

### 3. 검증 로직 (validation)
- 자동차 이름 길이(1~5자) 검증
- 빈 문자열, 공백, 중복 여부 확인
- 이동 횟수가 정수가 아니거나 1 미만인 경우 예외 발생
- 검증 실패 시 `IllegalArgumentException` 발생

### 4. 전진 로직 (racing)
- 각 자동차마다 0~9 난수 생성
- 난수가 4 이상이면 1칸 전진(`position + 1`)
- 자동차 상태를 문자열 형태로 출력
- 매 라운드마다 전체 자동차의 상태를 출력

### 5. 우승자 판정(winner)
- 모든 라운드 종료 후 최대 `position` 값을 가진 자동차 추출
- 동점일 경우 여러 자동차를 쉼표(`,`)로 연결
- `최종 우승자: Pobi, jub` 형식으로 출력
### 6. 출력 처리(output)
- 각 라운드마다 자동차별 진행 상태 출력
- 게임 종료 후 우승자 출력
